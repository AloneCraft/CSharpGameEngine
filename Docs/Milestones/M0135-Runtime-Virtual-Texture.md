- 日付: 2026-11-18
- 状態: Done
- 段階: ADR-0098 の段階 D の前倒し(ユーザーの判断。`Docs/目標、ロードマップ、戦略.md` は変えない)
- 決定: [ADR-0100](../Decisions/ADR-0100-Virtualized-Rendering.md) 決定 7
- 前の段階: [M0134](M0134-Tile-Pyramids-And-Terrain.md)(タイルの前処理と地形)。これで M0129〜M0135 の計画を終える
- 機能 ID: F-L5-052(地形の仮想テクスチャ)

## 用語
| 語 | 意味 |
|---|---|
| 仮想テクスチャ(RVT) | 地形の色を、マスごとの小さな画像(ページ)に作って、1 枚の大きな画像(置き場)に並べて貼る仕組み。要るマスのページだけを作る |
| 層の合成 | 色のタイル、急な所の岩の色、高い所の色などを、下から順に重ねてページの色を決めること |
| 置き場の画像 | ページを並べる 4096×4096 の画像。中身を後から書き換えられる(GPU を止めずに一部だけ送る) |
| 縁 | ページの周りの 1 テクセル。隣のページと同じ点の色を入れ、双線形で読んだときにつなぎ目が出ないようにする |

## 目的
- 地形の色を、層の合成でマスごとのページに作り、要る所だけ置き場に持つ。作り手は 2 種: ファイルの色のタイルを読む層と、実行時に高さと傾きから決める層。
- ページの番地はマスのキー(面、深さ、x、y)で、高さのタイルと同じ番地を使う。
- 統合の検証: 原本(色のタイル・元のメッシュ)と比べて差を測る。

## 作り
| 層 | 物 | 役目 |
|---|---|---|
| L5(Numerics) | `src/Numerics/World/Terrain/TerrainVirtualTexture.cs` | ページの作り手 `TerrainVirtualTexture`(縁つき、sRGB の 8 ビット)と層 `TileColorLayer`・`SlopeColorLayer`・`HeightColorLayer`。テクセルの点はマスの格子の分数の位置で、球は立方体の点の向き |
| L4 | `RenderTextureResource.CreateDynamic`、`RenderServer.UpdateTextureRegion` | 中身を書き換えられる画像(ミップは段 0 だけ、ほかの画像と共有しない)。一部の書き換えは画像の中身も変えるので、デバイスを作り直しても書き換えた後の画像 |
| L0 | `StageRenderer.UpdateTextureRegion` | 一部を一時の置き場に書き、次のフレームの最初に送る(GPU は待たない)。作ったばかりで丸ごとの送りを待つ画像には、その後に重ねて送る |
| L5 | `Terrain.VirtualTexture`・`ColorTiles`・`PageTexels` | マスの形を作るときにページを作って置き場の枠の場所へ送り、マスの UV を置き場のそのページの内側へ向ける。材質は置き場の画像を貼った 1 つ |

シェーダーは変えない(UV を置き場へ向けるだけ)。ページは枠と 1 対 1 で、マスが入れ替わると枠と一緒に使い回す。

## 検証の結果
- **ページと原本の色の差**(`TerrainVirtualTextureTests`、なめらかな色の 1024² の画像、ページ 64 テクセル、双線形で読む): 差の平均は 255 のうち 0.18〜0.22、最大 0.55(深さ 2・4・6)。8 ビットに詰める丸めとほぼ同じ。
- **隣のページとの縁**: 同じ点の色の差は 255 のうち 1 以内(つなぎ目が出ない)。
- **月**(`TerrainTests`、WARP、640×360、`.artifacts/m0135/`): LOLA の LDEM_64(23040×11520、int16、標高 = 値 × 0.5 m)を 59 秒でタイルの階層にした(8 段、5,460 タイル、723 MB)。LROC のカラー(16384×8192、16 ビット RGB、LZW)は 2 分 16 秒(238 MB)。段 0 の値は元の画像と一致。軌道の高さ 4,000 km からは 96 マス(深さ 2 まで)、30 km からは 1,776 マス(深さ 10 まで)。色を貼る前と後の絵を並べた `moon-orbit-rvt-compare.png`。
- **仮想ジオメトリと原本のメッシュ**の差は M0130 で測った(16 画素の下限と法線マップで、三角形 85% 減、6 m で 8 段より違う画素 0.08%)。

## 限界
- ページの色は、ページのテクセルの点で層を読む(前もって平均しない)。浅いマスほど原本の細部を点で拾う。
- 置き場は 4096²(縁込み 66 テクセルのページで 3,844 枚)。マスがそれより多いと、残りはまだ作れていないマスとして数え、作ってある粗いマスで代わりに描く。
- UV で貼る一般のメッシュは範囲外(位置から番地が決まる地形だけ)。
- 地形だけのレベルは読み込めない(描画器が物 1 つ以上を要る。地形のマスは後から足すため)。見本は小さな物を 1 つ置く。
