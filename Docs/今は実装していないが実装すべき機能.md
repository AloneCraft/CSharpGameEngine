# 今は実装していないが実装すべき機能

この文書はSimulation/Physicsの正式なDeferredバックログである。ここにある項目は`Implemented`ではなく、実装・試験・実動作確認が揃うまで全て`Deferred / NotVerified`とする。共通化するのは整数tick、Domain、Command/Event、Bake Artifact、翌tick Bridgeであり、異なる物理モデルを一つのSolverへ統合しない。

## Feature IDと自動Stage対応

機能ID、Stage ID、seed/tick、WARP、Oracleの詳細な正本は`Docs/Feature-Stages.md`と`FeatureStageCatalog.cs`である。以下28機能はF-L5-004〜F-L5-031を順に割り当て済みで、現時点のStage statusは全て`NotImplemented`である。
