# ADR-0002: ソースとアーティファクトの境界

## ステータス
採用済み

## コンテキスト
`CSharpGameEngine` では Bake 生成物やキャッシュを扱うため、再現性とCI移植性の観点で責務境界を明確にする必要がある。

## 決定
- `.cs` ファイルとオーサリングされた元アセットを正規の Source とする。
- Artifact と Cache は生成出力として扱う。
- Artifact は手編集しない。
- 同一の Bake パイプラインを CLI と CI の両方から呼び出せるようにする。
- Visual Studio 専用のビルド経路は導入しない。

## 根拠
- 正規Sourceを明確化することで、バージョン管理をクリーンかつ監査可能に保てる。
- Artifactを生成物として扱うことで、マージ競合や見えない差分蓄積を防げる。
- CLI/CI共通のBake入口により、開発者作業と自動化の一貫性を担保できる。

## 結果
- ビルド/Bakeスクリプトは決定的再生成を最優先に設計する必要がある。
- オーサリング利便機能であっても、正規Sourceフローを迂回してはならない。
