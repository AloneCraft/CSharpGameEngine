# Asset Workspace

- Intended status: Specified
- Decision: ADR-0081
- Feature: F-L8-035

## 表示と選択

Solution Explorer にアセット絞り込みを追加し、選択したフォルダー以下を下部 Assets に表示する。選択したアセットは親フォルダーの一覧で選択する。場所固定中は追従しない。Assets で 1 件を選ぶと、Solution Explorer でも同じファイルを選択する。ウィンドウを表示せず、フォーカスを奪わず、プロジェクトにないファイルでは何もしない。自分の選択が戻ってきた通知では、フォルダーの切り替えや再選択をしない。専用の「Solution Explorer で表示」ボタンは置かない。アセット選択はシーンのセッションを変更しない。

Assets の選択は、Solution Explorer の選択にも追従する。Solution Explorer でアセットを選ぶと Assets も選択し、フォルダーを選ぶと場所を合わせて選択を解除し、アセット以外のファイルを選ぶと選択を解除する。Assets の一覧の空き領域をクリックしても選択を解除する（スクロールバーと列ヘッダーの上は除く）。書類を開いたときなど、同じ場所・同じ一覧の選択通知では一覧を作り直さず、サムネイルのキャッシュも捨てない（アセット一覧そのものが変わったときだけ捨てる）。

Inspector（右側。アセットエディターの Details 列も同じ）は、種類によらず、上にヘッダー（相対パス・種類・状態・読み取り専用・アセット ID・参照）、その下に折りたためる節を並べる。「情報」の節は全種類でファイルの大きさ・更新日時・提供元を出し、モデルは頂点数・三角形数・大きさ・スキン・アニメーション数、テクスチャは画素の大きさ、音声（.wav）はサンプルレート・チャンネル・ビット深度・長さを足す（読むのに時間のかかる項目は非同期で足し、選択が変わったら捨てる）。取り込み設定や値の編集は、これまでどおり種類ごとの節（FBX・画像・データアセット）で行い、保存・Undo の経路は変えない。VS 標準のプロパティウィンドウには出さない（Scene-Inspector-UX-Design の「同時公開しない」の方針のまま）。

フォントは、Assets のタイルをそのフォント自身で描いた「Aa」（暗い背景）にする（`.cgefont` は字形の画素処理、`.ttf/.otf` は WPF。描ける字形がなければ汎用アイコンのまま）。タイルのツールチップ（開いたときに 1 回だけ読む）と Inspector の「フォント」の節に、UI の言語の例文（ja-JP は日本語、それ以外は英語の pangram）、`Aa Bb Cc 0123456789`、よく使う記号の行を実フォントで描き、描けない文字には赤い下線を引く。無い文字は実行時と同じく `?` で描く（`?` も無ければ何も描かない）。対応する代表的な言語（英・仏・独・西・葡・波・土・越・露・希・日・中（簡体）・韓・亜・泰）は、代表文字がすべて描ければ「対応」、一部なら「一部 (n/m)」、無ければ「未対応」、表示できない記号は一覧で出す。`.cgefont` の判定は字形の一覧（矩形のない字形は空白だけを描けるとみなす）、`.ttf/.otf` は `GlyphTypeface.CharacterToGlyphMap`。ブリッジの `AssetFontPreview` が指標と字形（文字コード・送り幅・矩形・UV）を運び、VSIX 側で検査する。`.cgefont` には元の TTF の対応表が残らないため、焼き込み時に無い文字が空の字形や .notdef で入っていても VSIX からは見分けられない。

Assets の上部に現在のフォルダーのフルパスは表示しない（Solution Explorer と選択が同期するため不要）。下端のステータス行（件数と診断）は残す。

右クリックメニューの先頭に「エクスプローラーで表示」を置く。アセットを 1 件選んでいれば、Windows のエクスプローラーでそのファイルを選択して開く（ファイルがなければ存在する親フォルダーを選択せずに開く）。選択がないとき（一覧の空白を右クリックすると選択を解除する）は、現在のフォルダーを選択せずに開く。2 件以上の選択では無効にする（エクスプローラーは 1 件しか選択できない）。開けるフォルダーがないときも無効にする。

明示的な「Assets で表示」は場所固定中でも対象のプロジェクト・フォルダーへ移動し、検索・種類・提供元・状態のフィルターを解除して対象を選択し、その位置へスクロールする。場所固定自体は解除しない。対象が登録一覧にない場合は理由を通知する。

初回は Output と同じ下部タブ群に高さ280 DIPで表示する。パッケージ初期化完了後に生成し、フォーカスを奪わない。以後の開閉・配置・サイズは VS が保存する。レイアウト適用コマンドはウィンドウを表示するだけで、配置は変えない。

一覧はシーン、モデル、テクスチャ、音声、グラフ、データ、フォントを対象とし、サムネイルと詳細一覧を切り替える。名前・種類・提供元・状態で検索・並べ替えする。お気に入りは場所と検索条件のみ。メタデータ、キャッシュ、bin/obj は独立した資産として出さない。サブアセットの識別はインポーターの結果を使う。

### アイコン

アセットの表示コマンド、タブ、「アセットのみ」フィルター項目はVS標準の`ImageGroup`で統一する。種類はシーン=`ThreeDScene`、モデル=`AbstractCube`、テクスチャ=`Image`、音声=`Sound`、シェーダーグラフ=`Shader`、データアセット=`DataTable`、フォント=`FontFile`、その他=`TextFile`。フォルダーはSolution Explorerの標準表示を維持する。

L8の共通対応表を一覧とInspectorで使い、`CrispImage`で表示する。タブ・コマンド・詳細一覧・Inspectorは16 DIP。タイルはサムネイル未取得・失敗時に中央32 DIPの種類アイコンを表示し、取得後は実画像と左上16 DIPの種類アイコンを併記する。ファイル名・種類・状態の文言を残す。

タイル右下12 DIPの状態バッジは失敗・無効メタデータ・ソース不足=`StatusError`、メタデータ不足=`StatusWarning`。読み取り専用は左下の`Lock`で独立表示し、エラーと併記できる。詳細一覧とInspectorでは16 DIPの状態アイコンと文言を使う。通常状態には追加バッジを付けない。提供元がReadOnly状態でも保持されたメタデータ診断を隠さない。正規サービスが取り込み中・再取り込み必要を通知する段階で、それぞれ`StatusRunning`／`StatusWarning`を使う。現在の未接続処理に進捗を捏造しない。表示用アイコンをContractsや保存形式へ追加しない。

明暗・高コントラスト、100／150／200％DPI、選択・無効状態を実機確認し、16 DIPでも識別できることを受け入れ条件とする。

### ウィンドウの責務と連携

| 場所 | 責務 |
|---|---|
| Solution Explorer | プロジェクト・フォルダー移動、アセットのみのフィルター、ファイル選択 |
| 下部 Assets | サムネイル／詳細一覧、検索、整理、参照確認、取り込み状態 |
| 右側 Inspector | 選択の情報、型付きデータの値、利用可能な取り込み設定 |
| 中央のドキュメント | シーン、コード、グラフ、モデルプレビュー等の既存エディター |

フォルダーツリーを下部へ複製しない。C#コードは通常のSolution Explorerとコードエディターで扱う。「アセットのみ」は対象ファイルと祖先フォルダーを残し、解除で通常表示に戻る。公開SDKのHierarchyフィルターを使用し、VSの内部実装や画面ツリーを書き換えない。Solution Explorer全体の右クリックメニューへエンジンコマンドを大量追加しない。

フォルダー選択で下部の場所を追従し、アセット選択では親を表示して該当行を選択する。下部での通常の選択ではツリーをスクロールせず、「Solution Explorerで表示」で明示的に同期する。「場所を固定」中はコードや他フォルダーへの移動で場所・検索結果を変えない。シーンの参照欄から逆引きでき、選択だけで配置先シーンのセッションを切り替えない。

### 表示状態と探索

初回表示はゲームプロジェクトを対象に、パッケージ初期化完了後に行う。初期化中に自分のウィンドウ生成を待たない。フォーカスを奪わず、既存ユーザーには新しいタブを一度だけ追加する。他のウィンドウを起動時に並べ直さない。「Game Engineレイアウトを適用」はゲーム エンジンのウィンドウを表示するだけで、並べ替えはしない（VS 18 ではドック指定が効かない）。配置を戻すときは、保存したレイアウトの適用か、VS のレイアウトのリセットを使う（[Editor-VSIX.md](Editor-VSIX.md) の「ウィンドウ配置」）。閉じる、フロート、サイズ変更、再起動では保存済み配置を優先する。

ツールバーは対象プロジェクト、場所・パンくず、名前検索、種類・提供元・状態、表示切替、作成、取り込み、整理、再取り込み、検索保存を提供する。初期検索範囲は選択フォルダー以下。「プロジェクト全体」へ切り替えられる。詳細列は名前、種類、相対パス、提供元、状態で並べ替える。お気に入りはフォルダーと検索条件への参照であり、ファイル移動や別分類階層を作らない。

取り込み中、再取り込み必要、失敗、読み取り専用はアイコンと文言で示し、色だけに依存しない。モデル内のメッシュ、マテリアル、クリップはインポーターが返すサブアセットとして展開する。表示名や配列番号から独自の識別子を作らない。選択数、処理状態、診断と参照確認の入口を表示する。複数選択時は共通情報と一括操作を示し、値の一括編集は初回対象外とする。

## 編集と整理

クリックは Inspector、ダブルクリックは種類別の専用エディターを開く（モデル・テクスチャ・音声・フォント・データアセット・シェーダーグラフは既定でフローティング、シーンは中央のドキュメント。詳細は `Asset-Editors.md`）。データアセットは既存の型検証を共用し、基本値・入れ子・配列をライブバッファに編集する。未対応構造は JSON 編集へ案内する。複数選択の値編集は初回対象外。

作成、取り込み、再取り込み、改名、移動、複製、削除を提供する。整理操作はソース、付随ファイル、メタデータ、シーン・グラフ・C#参照の事前変更案を提示する。生成物へ直接書き込まない。ID は移動で保持し、複製で新規発行する。参照中の削除には置換か参照解消が必要。競合・解析不能・権限不足は変更前に拒否する。未保存のバッファも検査する。操作全体を VS のネイティブ Undo に統合し、途中失敗では自分の変更のみ復元する。

任意の動的生成パスは完全解析保証の対象外。検出された未解決候補は中止理由として表示する。SDK・エンジン・NuGet 由来は読み取り専用で、プロジェクトへの複製を可能にする。通常の Solution Explorer の改名・削除にも同じ保護を適用する。

### 型別の編集契約

| 種類 | 編集・確認 |
|---|---|
| シーン | 既存シーンエディターのDesign / JSON |
| シェーダーグラフ | 既存グラフエディター |
| モデル | 既存プレビューホストと対応する取り込み設定 |
| テクスチャ・音声・フォント | 内容のプレビュー、利用可能な情報・設定。画像加工・波形加工は外部ツール |
| .cgeasset | Inspectorで型に従って値を編集し、中央ではJSONを開ける |
| その他 | 既定エディターを開き、専用編集への未対応を明示 |

.cgeassetの型・検証規則はシーン解析・スキーマと共有する。数値、真偽値、文字列、列挙、ベクトル、入れ子、配列を対象とする。対応できない構造は元の値を保持してJSON編集へ案内する。型の解決失敗、無効な値、外部更新との競合では書き込みを中止し、問題箇所を示す。開いているドキュメントのライブテキストバッファを編集し、VSの保存・Undo/Redoと統合する。Inspector専用の値や編集履歴を持たない。失敗・変更なしの操作でUndo履歴を増やさない。

「作成」に出すのはシーン、シェーダーグラフ、利用可能な[DataAsset]型、フォルダー。保存形式・実装がない種類を表示しない。モデルの配置と型に合う参照欄へのドロップを提供し、対応しない種類はドロップ不可とする。シーンへの書き込みは現在のセッション操作を使い、旧書き込み経路を復活させない。

### 整理操作の整合性

改名・移動の変更案にはソース、付随ファイル、メタデータ、シーン・グラフの参照、生成されたAssets.*シンボルを使うC#ソースを含める。C#はRoslynのシンボル解析、JSONとグラフはそれぞれの正式な解析器を使う。文字列の一括置換と生成済み.g.csの直接編集を禁止する。実行前に対象と参照更新を提示する。

書き込み権限、未保存バッファ、名前衝突、解析不能な参照候補、スナップショットの変更を確認し、問題があれば変更前に停止する。移動・改名は既存IDを保持する。複製は新しいIDを発行し、複製範囲内の参照のみ新しい対象へ向け、外部依存は共有する。参照中の削除は型の合う置換先へ更新するか、参照が解消するまで実行しない。削除は復元可能とする。

ファイル操作と参照バッファ更新を一つのネイティブUndo単位へまとめる。失敗時は当該操作が変更した対象のみ戻し、無関係な変更を巻き戻さない。プロセス中断からの回復情報は操作中の復旧専用であり、通常の編集履歴として使用しない。通常のSolution Explorer改名・削除もプロジェクト変更通知で同じ計画へ誘導する。外部ツールの変更は検出・再解析し、勝手に参照を書き換えない。動的パス等の安全を確認できない整理操作は未解決候補を示して中止する。

## 責務

L8 は表示、選択、VS のライブバッファと Undo を所有する。Content/L7 はメタデータと依存解析、取り込みを所有する。通信は Contracts の DTO のみ。対象一覧は開いているゲームプロジェクトの評価済み項目から取得する。索引は再生成できる。表示のために永続 ID やソースを書かない。旧 GUID メタデータは明示変換し、正規ライターを Content に統一する。

Contractsは一覧項目、検索要求、選択対象、整理変更案、処理結果を定義する。項目には所有プロジェクト、ソース位置、種類、提供元、可能な操作、診断を持たせる。永続IDがある場合は既存のAssetKeyを使い、未登録ソースは位置で追跡する。一覧、索引、サムネイルは再生成可能な派生データとする。

対象は開いているソリューションのゲームプロジェクトと、その評価済みアセット・プラグイン項目から求める。エンジン全体の再帰検索で別プロジェクトを混在させない。ゲームとプロジェクト内プラグインは編集可能、SDK・エンジン・NuGet由来は読み取り専用とし、「プロジェクトへ複製」で新しい編集可能資産にする。

VSIXへインポーターや別レンダラーを追加しない。M0114の正規サービス・配布成果物を接続し、基盤の全面移行を重複実装しない。未接続の取り込み操作を成功扱いにせず、新たな旧CLIフォールバックで穴埋めしない。旧Watcherの生成を廃止し、旧GUID保持の明示変換と新規登録を同じ正規ライターへ統一する。閲覧だけでは変更せず、通常処理に旧形式互換リーダーを残さない。

## 受け入れ条件

Debug/Release の単体・統合テスト、10,000件でのキャンセル、外部変更と競合、複数プロジェクトとプラグイン、メタデータ移行、参照更新、型検証、Undo/Redo、中断復旧を検証する。英日、明暗テーマ、DPI、フォーカス、ドッキングとドラッグは Experimental Instance で確認する。取り込みの完成には M0114 の統合・配布検証を要する。

| 表示・連携 | 新規環境の下部タブ結合、初回フォーカス、再起動・閉じる・フロート・位置変更・明示再適用、選択の循環なし |

| 整理 | シーン・グラフ・C#型付き参照の改名／移動後のビルド・実行、ID保持／重複防止、大小文字のみ改名、競合、読み取り専用、途中失敗、Undo/Redo、中断復旧 |

自動テストだけで実画面確認済みとはしない。仕様、実装台帳、実測仕様、適合状況、マイルストーン、利用手順を同じ作業で整合させ、作業中の他機能の変更を保持する。完成条件は素材を探し、下部で比較し、Inspector／専用エディターで編集し、参照を壊さず整理できること。ウィンドウ表示だけでは完了としない。現時点の実装と未達項目は[M0123](../Milestones/M0123-Asset-Workspace.md)へ記録する。

## Image and FBX interpretation

The authoritative interpretation is [Image and model interpretation](Image-And-Model-Interpretation.md). Image source rows expose registered outputs in details/Inspector. The Inspector offers output/default/settings edits, source preview and advisory Normal detection. Output kind/key remain stable; a saved output's usage is changed by adding a new output. Removal requires a compatible replacement and reviewed metadata/reference edits. Image/Texture assignment checks the declared reference type; TextureUsageAttribute carries an explicit texture role. Missing Normal output is added without deleting Color. Unsupported decoders are reported separately from file-list recognition.

FBX Inspector shows importer-owned subasset kinds/IDs, Generic import flags, source-Take clips and additional frame ranges. These operations call the resident standalone authoring service; the VSIX does not decode model/image data. The complete native linked Undo and interactive shell acceptance matrix is still a runtime verification gate.

## 内容サムネイルの契約

画像は L7 Cook worker の `thumbnail-image` がソースを読み、WIC scaler で最大128pxへ縮小して PNG を返す。devenv と描画 host は source decoder を持たない。devenv が読む画像は、この小さい派生 PNG のみ。未対応 codec・破損・寸法上限超過は取得不可とし、種類アイコンを残す。

モデルと保存済み scene は既存 SceneView の解析・外部 model facade を共有し、実 geometry・基本色を `EditorPreview.Host --thumbnail` の不可視128pxサーフェスで描画する。完全な材質・テクスチャ・作者の照明・アニメーションを再現する画像ではなく、game DLL や editor world を起動しない。宣言のない空groupは描画せず子のworld変換を保持し、欠損・未対応meshをplaceholderへ置換しない。primitive生成物はプロセス専用の一時cacheに限定し、sourceのAssetsへ書かない。

可視タイルが要求を開始し、画面外・一覧破棄で購読を取消す。共有schedulerは1処理、待機32件、PNGから作るfrozen bitmapのLRUは128件・8MiBまで。同一要求を共有し、一つの購読取消で他の可視購読を中断しない。source位置・長さ・更新時刻、metadata hash、project version、refresh世代と利用可能なAssetId+SubAssetIdをcache識別子に含める。子の実artifact/selectorが未接続の場合に親の画像で代用しない。scene全体で25万頂点・75万index、転送32MiB、画像source64MiBを超える要求は取得不可とする。これらはauthoritative assetの制限ではなく派生previewの作業上限である。

PNGは一時ファイル完成後にatomic publishし、失敗時に既存の出力を置換しない。閲覧はmetadata、永続ID、import manifestを生成しない。内容サムネイルの実画面・GPU・Debug/Releaseの受入状況はM0123で区別して追跡する。
